# 🏨 Hospitality Analytics Project

## 📊 Project Overview

The **Hospitality Analytics Project** is a data analytics project focused on analyzing hotel booking data to identify important business insights related to **bookings, revenue, cancellations, customer behavior, and hotel performance**.

The project uses **Power BI** to transform raw hospitality data into an interactive dashboard that helps stakeholders understand business performance and make data-driven decisions.

## 🎯 Objectives

* Analyze overall hotel booking performance.
* Identify booking and cancellation trends.
* Compare hotel performance.
* Analyze revenue and average daily rate.
* Understand customer booking behavior.
* Identify important business KPIs.
* Build an interactive Power BI dashboard for decision-making.

## 🛠️ Tools & Technologies

* **Power BI** – Data visualization and dashboard development
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and KPI calculations
* **Excel** – Data source and preprocessing
* **Git & GitHub** – Project version control

## 📈 Key KPIs

The dashboard includes important hospitality KPIs such as:

* 🏨 Total Bookings
* 💰 Total Revenue
* 📅 Average Daily Rate (ADR)
* ❌ Cancellation Rate
* 👥 Total Guests
* 🛏️ Room/Hotel Performance
* 📊 Booking Performance

## 📊 Dashboard Features

* Interactive KPI cards
* Hotel performance analysis
* Booking analysis
* Cancellation analysis
* Revenue analysis
* Customer segmentation
* Interactive filters and slicers
* Drill-down analysis
* Dynamic visualizations

## 🔍 Key Business Questions

The project helps answer questions such as:

1. What is the total number of bookings?
2. What is the total revenue generated?
3. What is the cancellation rate?
4. Which hotel performs better?
5. What is the average daily rate?
6. Which booking types contribute the most revenue?
7. How does customer behavior vary?
8. What factors are associated with booking cancellations?
